NightShot Screenshot Privacy Policy

Updated: 25 October 2026.

NightShot is a Windows screenshot utility. It does not require an account. It has no application analytics, advertising identifiers, or built-in telemetry.

Screen capture and text recognition

Screenshots are captured when you request a capture. The current capture is processed in memory. Text recognition runs on your device using Windows OCR or downloaded PaddleOCR models. NightShot does not send images or recognized text to a cloud recognition service. A temporary mouse hook protects input while a capture opens and an early drag finishes; it is not a background input recorder.

Local storage

NightShot stores settings, recent screenshot history, downloaded OCR models, and local application logs in your Windows user profile. History is limited to 40 recent images and can be cleared from the application. Text placed on the clipboard is handled by Windows and any clipboard features you have enabled. Files you save to a location you choose remain there until you delete them.

Diagnostic capture/selection tracing is off by default. If explicitly enabled for troubleshooting, it records timing, capture generation numbers and numeric selection geometry, without screenshot pixels or recognized text. Logs are not automatically uploaded to the developer.

Some error diagnostics also record numeric selection geometry. Separately enabled storage-path diagnostics contain local folder and executable paths, which may include your Windows user name. These reports remain local unless you choose to share them for support. NightShot does not add its own encryption to local screenshot files; protect your Windows account and saved files.

Optional public image upload

Only when you choose the upload action does NightShot send the selected PNG image, including its annotations, over HTTPS to https://x0.at/. The service returns a public link. The image is not protected by a NightShot account or password. Anyone who obtains the link may access or redistribute the image. Do not upload private, personal, financial, medical or other confidential content.

The hosting service receives the image and normal network request information, including your IP address and the NightShot version in its user-agent. Its storage and retention practices are controlled by that independent service. NightShot does not provide a remote deletion function or guarantee that a publicly uploaded image can be recalled. Clearing local history does not delete an uploaded image. You can use local capture, saving and OCR without uploading.

OCR model downloads

When you choose to download a language pack, NightShot requests public model files from https://www.modelscope.cn/ and, if necessary, from the NightShot model release at https://github.com/smmisha/nightshot-ocr-models/. GitHub may serve files through its download CDN. These services receive normal download request information such as your IP address. Screenshots and recognized text are not part of model download requests. Downloaded files are checked against pinned sizes and SHA-256 hashes before use.

Windows and third-party components

Windows, Microsoft Store and Microsoft Edge WebView2 Runtime have their own update, diagnostic and privacy settings. Their platform behavior is separate from NightShot's application networking. Opening a link at your request also uses your system browser and that website's own privacy practices.

Your controls

You decide when to capture, save, recognize text and upload an image. You can clear screenshot history, disable startup with Windows, and uninstall NightShot. Uninstalling an MSIX package removes its package-managed private data; files saved outside that storage, pre-existing data from an unpackaged installation, Windows clipboard data and remotely uploaded images are not erased by that operation. Keep any files you want to retain before uninstalling.
